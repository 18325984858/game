一、成功的骨骼渲染数据流
================================================================================

  STExtraBaseCharacter (玩家角色 Actor)
    │
    ├── Mesh (offset 0x650)
    │     → SkeletalMeshComponentBudgeted (运行时类)
    │         ├── SkeletalMesh (offset 0x7F0)
    │         │     → SkeletalMesh UObject (骨骼网格资产)
    │         │         └── FReferenceSkeleton (offset 0x238)
    │         │               └── RawRefBoneInfo: TArray 
    │         │                   stride=16: {FName(8), ParentIndex(4), pad(4)}
    │         │                   ★ 这是全身骨骼名称来源 (pelvis, spine, head...)
    │         │
    │         ├── CachedComponentSpaceTransforms (offset 0xBB8)
    │         │     → TArray<FTransform>  每个 0x30 字节
    │         │     ★ 骨骼变换数据 (组件空间)
    │         │
    │         ├── ComponentToWorld (offset 0x1F0)
    │         │     → FTransform  0x30 字节
    │         │     ★ 组件→世界 变换矩阵
    │         │
    │         └── MasterPoseComponent (offset 0x7F8)
    │               → TWeakObjectPtr → 父骨骼组件
    │
    ├── AvatarComponent (offset 0x3B98)
    │     ├── MasterBoneComponent (offset 0x300) → SkeletalMeshComponent
    │     ├── meshComponentList (offset 0x528) → TSparseMap<int32, UObject*>
    │     └── SkeletalMeshCompPool (offset 0xF10) → TArray<UObject*>
    │
    ├── FPPComp (offset 0x4168)
    │     └── _AvatarComp (offset 0x380) → AvatarComponent
    │
    ├── DefaultCharacterMesh (offset 0x4630) → SkeletalMesh 资产
    └── LastSkeletalMesh (offset 0x4790) → SkeletalMesh 资产


二、骨骼解析步骤 (resolveTrackedBoneIndices)
================================================================================

  输入: SkeletalMesh 资产指针
  输出: 17个骨骼槽位 → 骨骼索引 映射

  步骤1 (★ 关键路径 — 成功绘制骨骼的核心):
    读取 SkeletalMesh + 0x238 → FReferenceSkeleton.RawRefBoneInfo
    这是一个 TArray, 每个元素 16 字节:
      +0x00: FName Name     (8 bytes, 骨骼名称)
      +0x08: int32 ParentIndex (4 bytes, 父骨骼索引)
      +0x0C: padding        (4 bytes)
    
    此 TArray 包含完整的全身骨骼:
      pelvis, spine_01, spine_02, spine_03, neck_01, head,
      clavicle_l, upperarm_l, lowerarm_l, hand_l,
      clavicle_r, upperarm_r, lowerarm_r, hand_r,
      thigh_l, calf_l, foot_l,
      thigh_r, calf_r, foot_r,
      ... (通常 60-120 个骨骼)

  步骤2 (回退路径):
    SkeletalMesh + 0x48 → Skeleton → RefBoneNames (offset 0x280)
    ⚠️ 这个路径在当前版本只返回 17 个手部骨骼 (hand_l, thumb等)
    不能用于全身骨骼渲染

  步骤3 (暴力扫描回退):
    扫描 SkeletalMesh 对象 [0x3F0, 0x800] 范围
    查找看起来像骨骼 TArray 的数据结构
    尝试 stride = 24, 20, 16, 12, 8


三、骨骼候选组件发现 (fillPlayerSkeleton)
================================================================================

  按优先级收集 SkeletalMeshComponent 候选:

  1. Character.Mesh (offset 0x650)
     └ 最直接的路径, 始终存在

  2. Character.Mesh → MasterPoseComponent 链 (offset 0x7F8)
     └ TWeakObjectPtr, 通过 GUObjectArray 解析
     └ 最多跟随 4 层

  3. AvatarComponent.MasterBoneComponent (offset 0x300)
     └ 完整对局中通常有全身骨骼
     └ MasterBone → MasterPose 链

  4. AvatarComponent.meshComponentList (offset 0x528)
     └ TSparseMap 遍历 (inline bitarray + secondary)
     └ Entry: { int32 key, pad, UObject* value, ... } = 24B

  5. AvatarComponent.SkeletalMeshCompPool (offset 0xF10)
     └ TArray<UObject*> 简单遍历

  6. FPPComp._AvatarComp.MasterBoneComponent
     └ 第一人称组件的 Avatar 回退路径

  每个候选读取 CachedComponentSpaceTransforms, 记录 transformCount.
  按 transformCount 降序排列, 选有最多变换数据的组件.


四、世界坐标变换
================================================================================

  对每个追踪骨骼槽位 (共17个):
    1. 从 CachedComponentSpaceTransforms[boneIndex] 读取 FTransform (0x30字节)
    2. 从 ComponentToWorld 读取组件→世界变换 FTransform
    3. 先缩放: scaled = boneLocal * componentToWorld.scale3D
    4. 再旋转: rotated = quatRotate(componentToWorld.rotation, scaled)
    5. 最后平移: worldPos = rotated + componentToWorld.translation
    6. 检查坐标有效性 (isFinite, 合理范围)


五、屏幕投影与绘制 (UE4Draw.cpp)
================================================================================

  1. 世界坐标 → 相机空间 (transformWorldToCamera)
     使用 CameraManager 的 camLoc/camPitch/camYaw/camRoll

  2. 相机空间 → 屏幕坐标 (projectBonePoint)
     透视投影: focalLength = screenW / (2 * tan(FOV/2))
     sx = screenW/2 + camX * focal / camZ
     sy = screenH/2 - camY * focal / camZ

  3. 绘制骨骼线段 (drawPlayerSkeleton)
     16条线段连接:
       脊柱: Pelvis→SpineLower→SpineUpper→Neck→Head
       左臂: SpineUpper→LeftUpperArm→LeftLowerArm→LeftHand
       右臂: SpineUpper→RightUpperArm→RightLowerArm→RightHand
       左腿: Pelvis→LeftThigh→LeftCalf→LeftFoot
       右腿: Pelvis→RightThigh→RightCalf→RightFoot
     关节点: 4px 青色圆 + 5.5px 黑色描边

  4. 条件: boneMask != 0 且 m_enableSkeleton 且 有精确相机数据


六、17个追踪骨骼槽位定义
================================================================================

  槽位  名称         主要别名
  ──────────────────────────────────────
  0     Pelvis       pelvis, root, hips
  1     SpineLower   spine_01, spine
  2     SpineUpper   spine_03, spine_02, chest
  3     Neck         neck_01, neck
  4     Head         head
  5     LeftUpperArm upperarm_l, clavicle_l
  6     LeftLowerArm lowerarm_l, forearm_l
  7     LeftHand     hand_l
  8     RightUpperArm upperarm_r, clavicle_r
  9     RightLowerArm lowerarm_r, forearm_r
  10    RightHand    hand_r
  11    LeftThigh    thigh_l
  12    LeftCalf     calf_l
  13    LeftFoot     foot_l
  14    RightThigh   thigh_r
  15    RightCalf    calf_r
  16    RightFoot    foot_r
